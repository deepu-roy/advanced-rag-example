# System Access Approval Process

Any request for access to an internal system — VPN, a production database,
an internal admin tool, or a shared drive containing customer data —
follows the same two-step approval process, regardless of which system is
involved.

Step one: the requester's manager (for employees) or sponsoring employee
(for contractors) approves the business justification in the access
request ticket. Step two: IT Security reviews the request against the
principle of least privilege and either approves, denies, or asks for
scope to be narrowed. Both approvals must be recorded in the ticket before
the account is provisioned.

For contractors specifically, sponsorship also requires the sponsoring
employee to confirm that a signed contractor agreement and, where
applicable, a certificate of insurance are on file with Legal. Contractor
access is provisioned for a maximum of 90 days at a time and must be
re-approved on expiry — it does not renew automatically. Access approvals
are audited quarterly, and any account without an active approval on file
is disabled.
