# Password Policy

Passwords for Northbridge's single sign-on account must be at least 14
characters long. There is no requirement to mix character types, since
length matters more than complexity for resisting modern password-cracking
techniques, but reused passwords from other services are not allowed and
are checked against a breached-password list at set time.

Passwords do not expire on a fixed schedule; instead, a password is
required to be changed only if it is detected in a credential breach, or if
IT Security has reason to believe an account may have been compromised.
This replaces the company's older 90-day rotation policy, which was
retired because forced rotation was found to encourage weaker, more
predictable passwords.

All employees are required to use the company-provided password manager to
generate and store credentials for any work-related account, rather than
memorizing or reusing passwords. Sharing a password with another employee,
even a manager, is a policy violation regardless of the reason.
