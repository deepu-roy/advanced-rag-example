# Return Merchandise Authorization (RMA) Process

A return merchandise authorization, or RMA, is required before any
shipment can be returned to a customer's origin facility or redirected to
a different destination. An RMA exists so that a returned shipment can be
tracked, reconciled against billing, and matched back to the original
order.

To start an RMA, the customer or account manager submits a return request
through the customer portal, stating the reason: damage, wrong item,
customer refusal, or a change of order. Operations reviews the request
within one business day and, if approved, issues an RMA number that must
be labeled on the physical shipment before pickup. Shipments returned
without a visible RMA number are held at the destination warehouse pending
manual reconciliation, which can add several days to processing.

Once a returned shipment arrives back at the origin facility and is
scanned against its RMA number, any applicable billing adjustment is
generated automatically. RMAs that are not used within 30 days of issuance
expire and must be reissued.
